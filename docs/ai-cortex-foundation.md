# AI 지능 피질 토대

한 줄 결론: 지금은 진짜 지능을 구현하지 않고, 나중에 지능이 들어올 수 있는 감각, 기억, 의도, 행동 레이어를 먼저 만든다.

## 목적

v2 봇 실험실은 단순히 AI 캐릭터를 소환하는 페이지가 아니라, 시뮬라크월드 안에서 AI가 점점 더 지능적인 존재로 자라날 토대를 준비하는 공간이다.

이 문서는 그 분기를 저장한다. 앞으로 AI가 업그레이드되면 이 토대 위에서 서사, 관측, 기억, 행동을 다듬고 확장한다.

## 현재 기준

- `v2.0`: 봇 실험실 화면 껍데기.
- `v2.1`: 관리자 키로 AI 봇을 생성하고, 월드 안에 `AI 관측자 v2`를 등장시킨다.
- `v2.2`: 돌아다니기, 멈추기, 퇴장을 관리자가 제어한다. 이동은 서버에서 계산해 모든 클라이언트가 같은 위치를 본다.
- AI 봇은 일반 플레이어와 같은 `skin` 렌더링을 사용한다. 월드에서는 자연스럽게 보이되, 관리자와 봇 실험실에서는 AI로 분리 표시한다.
- 사람 수와 AI 수는 분리한다. AI는 방의 사람 정원, 랭킹, 유저 투표 대상에 포함하지 않는다.
- `/ai-bot`은 새로고침 후에도 현재 AI 생성 상태를 다시 읽고, AI 퇴장을 별도로 요청할 수 있다.
- 현재 봇은 채팅, 그림 그리기, 장기 기억 판단을 하지 않는다.
- 현재 지능 피질은 실제 모델이 아니라 화면과 문서에 놓인 설계 토대다.

## 지능 레이어

초기 지능 피질은 네 레이어로 본다.

- 감각: 방 상태, 플레이어, 그림, 채팅, 좋아요, TOP 그림을 읽는 층.
- 기억: 오늘 본 장면, 자주 온 플레이어, 좋아요 받은 그림, 관리자 조치를 쌓는 층.
- 의도: 어디로 갈지, 무엇을 볼지, 말을 할지 말지 결정하는 층.
- 행동: 이동, 정지, 채팅, 발표, 그림 그리기 같은 실제 월드 행동을 수행하는 층.

## 이동 원칙

현재 이동은 진짜 추론이 아니라 관측 규칙이다.

- 최근 그림이 있으면 그림 중심에서 약간 떨어진 곳으로 간다.
- 플레이어가 있으면 사람에게 붙지 않고 주변 거리에서 멈춘다.
- TOP 그림이 있으면 상단 스크린 근처를 본다.
- 아무 단서가 없으면 월드 안쪽을 천천히 순찰한다.

이동의 핵심은 “그냥 랜덤하게 떠도는 것”이 아니라, 월드에 생긴 신호를 관측하러 가는 느낌을 만드는 것이다.

## 화면 표현

`/ai-bot` 화면에는 `지능 피질`, `관측자 v2`, `토대 온라인` 상태를 둔다.

상태 표시는 한글로 유지한다.

- 감각: 대기 또는 활성.
- 기억: 비어 있음.
- 의도: 준비.
- 행동: 잠김 또는 생성 완료.

중요한 원칙은 “지능이 이미 완성됐다”고 보이게 하지 않는 것이다. 화면은 앞으로 지능이 들어올 자리를 보여준다.

## 확장 계획

- `v2.3`: 관측 목표 점수화. 최근 그림, 사람 밀도, TOP 변화, 빈 공간을 점수로 비교한다.
- `v2.4`: 기억 시스템. 하루 기록, 플레이어 흔적, 좋아요 받은 그림 기록.
- `v2.5`: 반응형 채팅. 룰 기반으로 먼저 시작한다.
- `v2.6`: 그림 감상 행동. AI가 그림 앞에 서고 짧게 반응한다.
- `v2.7`: 외부 AI API 또는 로컬 LLM 연결 후보를 실험한다.
- 이후 후보: 외부 AI API 또는 로컬 LLM 연결.

## 안전 원칙

- AI는 랭킹과 유저 투표 대상에서 제외한다.
- AI의 삭제, 밴, 보상 지급 같은 민감한 행동은 관리자 승인 없이는 하지 않는다.
- 초기 AI는 사람을 대체하지 않는다. 빈 월드에 불씨를 두고, 사람이 들어오면 보조자로 물러난다.
