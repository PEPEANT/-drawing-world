# 시뮬라크 아레나 전환 계획

한 줄 결론: 자유드로잉 v1은 `simulac-world-free-drawing-v1` 태그로 보존하고, 이후 개발은 `simulac-arena` 브랜치에서 PvP 중심으로 전환한다.

## 현재 저장 상태

- 저장 태그: `simulac-world-free-drawing-v1`
- 새 개발 브랜치: `simulac-arena`
- 전체 게임명: 시뮬라크월드
- 새 메인 모드: PvP 아레나
- 보존된 이전 모드: 자유드로잉 v1

자유드로잉은 당장 메인에서 계속 밀지 않는다. 필요하면 태그에서 다시 꺼낼 수 있는 세이브 파일로 둔다.

## 전환 원칙

아레나는 완전한 빈 프로젝트가 아니다. 기존 코드에서 쓸 수 있는 뼈대는 유지하고, 그림판 전용 기능은 제거하거나 숨긴다.

남길 것:

- 서버 접속 구조.
- 방/로비 구조.
- 플레이어 이동.
- 스킨과 스킨 선택.
- 채팅.
- 관리자 페이지.
- 밴/경고/강퇴.
- 랭킹 구조 일부.
- AI 관측실.

뺄 것:

- 붓 도구.
- 지우개.
- 레이어.
- 그림 내보내기.
- 그림판용 색상/브러시 패널.
- 자유드로잉 중심 설명.

새로 만들 것:

- 팀 배정.
- 체력.
- 역할 선택.
- 공격 판정.
- 스킬 쿨타임.
- 리스폰.
- 경기 시간.
- 점수판.
- 승패 결과.
- PvP용 상점/스킨 보상 구조.

## PvP v0.1 목표

처음 목표는 큰 RPG나 완성형 AOS가 아니다. 작고 빠르게 재미를 확인하는 2팀전이다.

기본 규칙:

- 2팀전.
- 3분 경기.
- 플레이어는 스킨을 유지한다.
- 서버가 체력과 공격 판정을 관리한다.
- 사망 시 일정 시간 뒤 리스폰한다.
- 점수 조건을 만족하거나 시간이 끝나면 승패를 표시한다.

초기 역할 후보:

- 공격형: 빠르고 근접 피해가 강함.
- 원거리형: 투사체를 쏘지만 체력이 낮음.
- 힐러형: 약한 공격과 아군 회복.

v0.1에서는 역할 3개를 넘기지 않는다.

## 핵심 재미 가설

자유드로잉은 창작 흔적을 남기는 재미가 있었지만, 반복 접속 이유가 약했다.

아레나는 다음 재미를 검증한다.

- 내 스킨으로 싸우는 재미.
- 팀으로 이기는 재미.
- 짧은 경기 후 바로 재도전하는 재미.
- 역할을 바꿔보는 재미.
- 상점에서 외형을 꾸미는 재미.

이 가설이 맞으면 시뮬라크월드는 드로잉 중심이 아니라 아레나 중심으로 전환한다.

## 구현 순서

1. 화면 이름을 시뮬라크월드 / PvP 아레나로 변경.
2. 로비를 전투 입장 흐름으로 바꿈.
3. 드로잉 도구 UI를 숨기거나 제거.
4. 서버에 PvP 방 상태 추가.
5. 플레이어 상태에 팀, 체력, 역할, 리스폰 상태 추가.
6. 클라이언트 입력을 공격/스킬 입력으로 확장.
7. 서버 기준 공격 판정 구현.
8. 점수판과 경기 시간 표시.
9. 결과 화면 추가.
10. 관리자 페이지에 PvP 상태 표시.
11. AI 관측실에 PvP 방 관측 추가.

## 주의점

PvP는 그림판보다 판정에 민감하다.

클라이언트가 "내가 때렸다"를 결정하면 조작 가능성이 커진다. 클라이언트는 입력을 보내고, 서버가 체력과 공격 판정을 결정하는 방향으로 가야 한다.

상점은 처음부터 능력치 판매를 하면 안 된다. 초반 상점은 스킨, 테두리, 칭호, 말풍선, 승리 포즈 같은 장식 중심으로 둔다.
