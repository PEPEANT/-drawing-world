# 시뮬라크 아레나 전환 계획

결론: 자유드로잉 v1은 `simulac-world-free-drawing-v1` 태그로 보존하고, 이후 실험은 `simulac-arena` 브랜치에서 PvP 중심으로 진행한다.

## 저장 상태

- 보존 태그: `simulac-world-free-drawing-v1`
- 개발 브랜치: `simulac-arena`
- 플랫폼 이름: 시뮬라크월드
- 현재 메인 모드: PvP 아레나
- 이전 모드: 자유드로잉 v1

자유드로잉은 메인에서 계속 끌고 가지 않는다. 필요하면 태그에서 다시 꺼낼 수 있는 보존판으로 둔다.

## 전환 원칙

아레나는 완전 새 프로젝트가 아니라 기존 온라인 구조에서 쓸만한 뼈대만 남기고, 그림 전용 기능은 제거하거나 숨기는 방식으로 전환한다.

남기는 것:

- 서버 접속 구조
- 방 로비 구조
- 플레이어 이동
- 스킨과 스킨 선택
- 채팅
- 관리자 페이지
- 밴, 경고, 강퇴 구조
- 랭킹/투표 일부
- AI 관측실

빼는 것:

- 붓, 지우개
- 레이어
- 그림 내보내기
- 그림 전용 색상/브러시 패널
- 자유드로잉 중심 설명

새로 만드는 것:

- 팀 배정
- 체력
- 역할 선택
- 공격 판정
- 스킬 쿨다운
- 리스폰
- 점수판
- 승패 결과
- PvP 상점/스킨 보상 구조

## 구현 완료

PvP v0.1 골격은 들어갔다.

- 로비 이름과 사이트 이름을 `시뮬라크월드: PvP 아레나`로 변경했다.
- 로비에서 공격, 원거리, 힐러 역할을 선택할 수 있다.
- 인게임에서 붓/지우개/레이어/내보내기 UI를 제거했다.
- 중앙 점수판, 플레이어 체력 패널, 공격/스킬 버튼을 추가했다.
- 서버가 팀, 역할, 체력, 사망, 리스폰, 점수를 관리한다.
- 서버가 근접/원거리/힐러 역할별 사거리, 피해량, 회복량, 쿨다운을 처리한다.
- 역할 변경으로 체력을 회복하는 꼼수는 서버에서 막는다.
- 플레이어 위에 팀 링과 체력바를 그린다.
- WebSocket 테스트로 2명 접속, 팀 배정, 공격 피해 적용을 확인했다.

## PvP v0.1 목표

처음 목표는 RPG 완성이나 AOS 완성이 아니라, 작고 빠르게 재미를 확인하는 2팀 아레나다.

기본 규칙:

- 2팀전
- 서버 권위 체력/공격 판정
- 스킨 기반 캐릭터
- 역할 3개: 공격, 원거리, 힐러
- KO 시 팀 점수 증가
- 일정 시간 후 리스폰

현재는 “싸울 수 있는 뼈대” 단계다. 아직 밸런스 게임은 아니다.

## 다음 할 일

1. 경기 시작/종료 타이머를 추가한다.
2. 목표 점수 또는 제한 시간으로 승패를 표시한다.
3. 모바일 HUD를 더 작게 정리한다.
4. 공격 범위와 피격 피드백을 더 선명하게 보여준다.
5. 힐러 스킬을 아군에게 더 잘 보이게 표시한다.
6. 역할별 속도 차이를 넣을지 결정한다.
7. 랭킹을 좋아요가 아니라 KO/승리 기준으로 바꾼다.
8. 관리자 페이지에 PvP 상태, 점수 초기화, 경기 강제 종료 버튼을 추가한다.
9. AI 관측실에서 PvP 방 상태를 읽게 한다.
10. 상점은 능력치 판매가 아니라 스킨, 테두리, 칭호, 말풍선 같은 장식 중심으로 설계한다.

## 검증 질문

아레나는 다음 질문에 답해야 한다.

- 내 스킨으로 싸우는 재미가 있는가?
- 팀전이 자유드로잉보다 반복 접속 이유를 더 주는가?
- 역할을 바꿔보는 재미가 있는가?
- 피격과 KO가 충분히 명확한가?
- 점수판이 경쟁심을 만들 수 있는가?
- 상점이 붙어도 pay-to-win으로 보이지 않는가?

이 답이 긍정적이면 시뮬라크월드는 드로잉 중심이 아니라 아레나 중심으로 이동한다.

## 주의점

PvP는 그림보다 판정에 민감하다. 클라이언트가 “내가 때렸다”를 결정하면 조작 가능성이 커진다. 클라이언트는 입력만 보내고, 서버가 체력과 공격 판정을 결정해야 한다.

상점은 초반부터 능력치 판매를 하면 안 된다. 초반 상점은 스킨, 테두리, 칭호, 말풍선, 승리 포즈 같은 장식 중심으로 둔다.

이 태그는 삭제하지 않는다.
