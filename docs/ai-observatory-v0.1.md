# AI 관측실 v0.1

한 줄 결론: v0.1은 진짜 외부 AI 모델 호출이 아니라, 서버 상태를 읽고 판단/주제/발표를 수행하는 로컬 관측 엔진이다.

## 목적

AI 관측실은 유저 페이지와 관리자 페이지 사이에 있는 세 번째 페이지다.

이 페이지의 목적은 AI를 단순한 챗봇이 아니라, 시뮬라크월드의 상태를 관찰하고 다음 행동을 제안하는 존재로 실험하는 것이다.

## 현재 경로

- 페이지: `/ai`
- 인증: 관리자 키 사용
- 연결: 기존 `/admin-ws` 관리자 WebSocket 사용

## 현재 기능

- 방 목록 관측.
- 접속자, 플레이어, 선 기록, 채팅 수 표시.
- 최근 채팅 표시.
- 최근 선 기록의 작성자 쏠림을 보고 도배 가능성 판단.
- AI 판단 요약 표시.
- 관측 신호 표시.
- 오늘의 주제 3개 제안.
- 주제 문구를 채택해 발표 문구로 복사.
- 관리자가 승인하면 `AI 관측실` 이름으로 게임 채팅에 발표.

## 서버 흐름

1. AI 페이지가 관리자 키로 `/admin-ws`에 접속한다.
2. 클라이언트가 `aiRefresh` 메시지를 보낸다.
3. 서버가 `buildAiState()`로 방 상태를 요약한다.
4. 서버가 `aiState` 메시지로 관측 결과를 보낸다.
5. 클라이언트가 `aiAnnounce` 메시지로 발표를 요청한다.
6. 서버가 `AI 관측실` 채팅 메시지를 방에 저장하고 브로드캐스트한다.

## 현재 제한

- OpenAI API 또는 외부 모델 호출 없음.
- AI가 스스로 접속하거나 이동하지 않음.
- AI가 그림을 직접 그리지 않음.
- AI가 유저를 밴하거나 그림을 삭제하지 않음.
- AI의 민감한 행동은 아직 모두 관리자 승인 구조로만 다룬다.

## 다음 확장 후보

- GPT API를 선택적으로 연결해 주제와 판단 문구 품질 높이기.
- AI 발표 이력 저장.
- 관리자 페이지에 AI 승인 대기열 추가.
- AI 추천과 유저 좋아요 분리.
- AI가 안전한 드로잉 명령으로 간단한 선/도형 그리기.
- 도배 의심 시 관리자에게 더 강한 경고 카드 표시.
