# 드로잉온라인

흰 월드 위를 WASD로 걸어다니며 그림을 그리고 채팅하는 온라인 드로잉 웹게임입니다.

## 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

관리자 페이지는 `http://localhost:3000/admin?key=admin`으로 접속합니다.
운영 시에는 `ADMIN_KEY=원하는키` 환경 변수로 관리자 키를 바꾸세요.

## 주요 기능

- 로비, 닉네임, 스킨 선택 및 커스텀 스킨 편집
- 방 목록: `시뮬라크월드`
- WASD / 방향키 이동
- PC 단축키: `1` 붓, `2` 지우개, `T` 채팅
- 모바일 투명 조이스틱과 붓/지우개 버튼
- 실시간 그림, 채팅, 플레이어 위치 공유
- 레이어 추가, 이름 수정, 숨김, 투명도 조절, 미리보기
- 전체/부분 PNG 또는 JPG 내보내기
- 관리자 페이지에서 접속자 확인, 강퇴, 방 그림 초기화

## 파일 크기 관리

```bash
npm run check:size
```

- 250줄 초과: 분리 후보
- 350줄 초과: 경고
